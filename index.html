GICOP 2026 Code Comparison Tool

An interactive dashboard built using AI capabilities that maps every change between the General Insurance Code of Practice 2020 and the Draft 2026 Code - supporting impact assessment, value chain alignment, and regulatory readiness planning.

Designed to support human analysis and decision-making - materiality ratings reflect AI interpretation of code changes and require validation with full IAG context

Key Features

Purpose-built for regulatory change analysis and operational readiness planning.

AI-Powered Change Analysis

Automatically compares the full text of both Codes, identifies every change, classifies materiality, and generates plain-language summaries to accelerate human review and decision-making.

Section-by-Section Comparison

Click any section's compare link to view the GICOP 2020 and Draft 2026 text side-by-side, showing all clauses within that section for direct comparison.

Multi-Dimensional Filtering

Filter by section, materiality, change type, clause type, value chain (L1), and IIR recommendation association. Drill into exactly what matters.

Value Chain Mapping

Each clause is mapped to IAG's enterprise value chain (APQC-based L1/L2/L3) to identify which business processes are impacted by each change.

IIR Recommendation Cross-Reference

Industry Review Recommendations are mapped to relevant Code clauses, showing coverage status and gaps.

Full Document View

Read the complete GICOP 2020 and Draft 2026 text with searchable navigation - no need to switch between Word documents.

Interactive Dashboard

Filter, sort, search - all within a single self-contained HTML file.
